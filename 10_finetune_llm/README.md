# 🚀 Module 10 — Large Language Model (LLM) Fine-Tuning at Scale

> **Fine-Tuning 7B–70B Foundation Models** — scaling up from single GPU to multi-GPU orchestration, mixed precision, and distributed training backends.

---

## 🎯 Objectives & Scope
- **Target LLM Architectures:**
  - **Meta LLaMA 3.1 & 3.2** (8B, 70B)
  - **Mistral & Mixtral MoE** (7B, 8x7B, 12B NeMo)
  - **Qwen 2.5** (7B, 14B, 32B)
  - **DeepSeek-Coder & DeepSeek-V2/V3**
- **Distributed Training Engines:**
  - **Hugging Face Accelerate** with multi-GPU DDP (Distributed Data Parallel).
  - **DeepSpeed ZeRO Stages 1, 2, and 3** with CPU offloading.
  - **FSDP (Fully Sharded Data Parallel)** native in PyTorch.
