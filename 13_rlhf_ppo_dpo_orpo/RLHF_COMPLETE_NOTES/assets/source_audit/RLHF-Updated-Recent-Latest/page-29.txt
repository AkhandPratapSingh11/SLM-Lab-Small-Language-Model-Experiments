DQN works well for discrete action spaces because the number of actions is finite. It struggles with continuous action

spaces because it would need to estimate Q-values for infinitely many possible actions. Therefore, algorithms such as

PPO, DDPG, TD3, and SAC are typically used for continuous control problems like robotics and self-driving cars.
