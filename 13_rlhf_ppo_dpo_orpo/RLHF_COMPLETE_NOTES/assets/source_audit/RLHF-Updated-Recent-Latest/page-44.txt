Advariage

"PPO updates the policy" means PPO modifies the model's neural network weights so that actions (or responses) that

received higher rewards become more likely in the future, while lower-quality actions become less likely.

PPO Clipping

Suppose epsilon: € = 0.2

Allowed range: 0.8 to 1.2

PPO internally says: 1.58

+ Do not use it,

Instead: min(1.58, 1.2)

Use: 1.2

PPO clipping does not stop the neural network weights from being updated. Instead, the loss function limits the

gradient so that the weight update (and therefore the probability change) cannot become too large in a single

training step.

What Happens During the Weight Update?

This is a very important point. PPO does NOT directly do:

0.95 + 0.72

Instead, PPO designs the loss function in such a way that once:

ratio > 1.2

the model stops receiving additional benefit from increasing the probability further.

As a result: gradient becomes smaller

then: weight updates become smaller

and naturally: the new probability does not jump too much.

PPO is not a supervised learning because it does not learn from ground-truth labels; it learns from reward signals

generated by the environment or a reward model
