# ⚡ Module 09 — Universal Small Language Model (SLM) Fine-Tuning

> **Fine-Tune Any Small Language Model Under 3 Billion Parameters** — lightweight, high-speed domain adaptation for edge devices, consumer GPUs, and on-device AI.

---

## 🎯 Objectives & Scope
- **Supported SLM Architectures:**
  - **Microsoft Phi-3 / Phi-4** (Mini, Small)
  - **Google Gemma 2** (2B)
  - **Qwen 2.5** (0.5B, 1.5B, 3B)
  - **Hugging Face SmolLM** (135M, 360M, 1.7B)
  - **TinyLlama** (1.1B)
- **Universal Pipeline:**
  - Unified tokenization, chat templating (`tokenizer.apply_chat_template`), and PEFT setup.
  - Benchmarking throughput, memory footprint, and quality across different SLM families on the same task.
